# 🛒 Blinkit Sales Analytics Dashboard

## 1. Project Title / Headline

**🛒 Blinkit Sales Analytics: Interactive Sales & Outlet Performance Dashboard**

A dynamic, interactive Power BI dashboard designed to analyze Blinkit's sales performance across product categories, outlet types, outlet sizes, locations, customer ratings, and establishment years.

---

## 2. Short Description / Purpose

The Blinkit Sales Analytics Dashboard is a visually engaging and analytical Power BI report designed to transform raw sales data into meaningful business insights. The dashboard enables users to explore sales performance, product trends, outlet characteristics, and customer ratings through interactive KPIs, filters, and visualizations.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Main data visualization platform used for report creation.
- 📂 **Power Query** – Used for data cleaning, transformation, and preparation.
- 🧠 **DAX (Data Analysis Expressions)** – Used to create calculated measures and KPIs.
- 📈 **Data Visualization** – Interactive charts, KPI cards, slicers, and tables used to present business insights.
- 📝 **Data Modeling** – Used to structure the dataset and support filtering, aggregation, and analysis.
- 📁 **File Format** – `.pbix` for the Power BI dashboard and `.png/.pdf` for dashboard previews.

---

## 4. Data Source

The dataset used in this project is a **practice dataset** that I discovered through a YouTube tutorial while learning and practicing Power BI.

The dataset contains information related to Blinkit products, sales, outlets, locations, ratings, outlet sizes, outlet types, and establishment years.

While the dataset was sourced for practice purposes, the dashboard was independently developed to apply Power BI concepts including data transformation, DAX, KPI development, interactive filtering, and business-focused data visualization.

---

## 5. Features / Highlights

### • Business Problem

Raw sales data can contain valuable information about product and outlet performance, but analyzing large datasets manually can make it difficult to quickly identify trends and compare different business segments.

Key questions such as:

- Which product categories generate the most sales?
- Which outlet types perform best?
- How does outlet size affect sales?
- Which locations contribute the most to overall sales?
- How do customer ratings vary across different segments?
- How does sales performance vary based on outlet establishment year?

can be difficult to answer efficiently using raw data alone.

### • Goal of the Dashboard

The goal of this dashboard is to provide an interactive analytical tool that:

- Enables users to explore sales performance across multiple dimensions.
- Provides an overview of key business KPIs.
- Allows users to filter and compare products and outlets dynamically.
- Identifies trends and patterns within the sales dataset.
- Converts raw sales data into an easy-to-understand business intelligence report.

### • Walkthrough of Key Visuals

**- Key KPIs (Top Section)**

The dashboard provides a high-level overview of important metrics such as:

- Total Sales
- Total Items Sold
- Average Sales
- Average Customer Rating
- Discount-related metrics

These KPIs provide an immediate snapshot of overall business performance.

**- Interactive Filter Panel**

Users can dynamically filter the dashboard based on:

- Outlet Location Type
- Outlet Size
- Item Type

The filters update the dashboard visuals, allowing users to explore specific business segments.

**- Sales by Item Type**

A visual comparison of sales performance across different product categories, helping identify the categories contributing most to overall sales.

**- Fat Content Analysis**

Visualizes sales distribution based on product fat content, allowing users to compare performance across different product characteristics.

**- Sales by Outlet Size**

Compares sales performance across different outlet sizes to identify which outlet segments contribute most to overall revenue.

**- Outlet Location Analysis**

Provides a comparison of sales performance across different outlet location tiers, helping identify stronger and weaker geographical segments.

**- Sales Trend by Establishment Year**

Tracks sales performance across outlet establishment years to identify trends and changes in business performance over time.

**- Outlet Type Performance**

Provides a detailed comparison of different outlet types using key performance metrics, allowing users to understand how different outlet formats contribute to overall sales.

### • Business Impact & Insights

**Performance Analysis:**  
The dashboard provides a quick way to identify high-performing products, outlets, and business segments.

**Product Strategy:**  
Product-level analysis can help identify categories that contribute significantly to overall sales and those with lower performance.

**Outlet Optimization:**  
Comparing outlet sizes, types, and locations can help businesses understand which formats and segments perform better.

**Trend Analysis:**  
The establishment-year analysis provides insight into how sales performance varies across different generations of outlets.

**Data-Driven Decision Making:**  
By combining multiple business dimensions into a single interactive dashboard, the report enables faster exploration and more informed decision-making.
